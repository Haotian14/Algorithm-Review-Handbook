# 14 · 因果推断与 Uplift

> 前面所有章节做的都是**预测**：给定 $X$ 猜 $Y$。这一章做的是**决策**：如果我对这个人做某个动作，会**多带来**什么。
> 推荐、广告、增长、风控里凡是涉及「发不发券、推不推送、投不投放」的问题，本质都是因果问题。
> **这是相当一部分候选人的知识盲区，答得上就是明显的区分度。**

## 1. 为什么预测模型不够用

**经典的坑**：模型发现「领了优惠券的用户购买率是 60%，没领的是 20%」，于是结论"发券能提升 40 个点转化"。

错在哪？**去领券的人本来就是想买的人。** 券没有创造需求，它只是被高意愿用户领走了。
真实的因果效应可能是 0，甚至是负的（本来会原价买的人用券买了，白白损失利润）。

这就是**混杂（confounding）**：购买意愿同时影响了「是否领券」和「是否购买」。

**辛普森悖论**是它最戏剧化的形式：分组看每一组都是 A 更好，合起来却是 B 更好。
原因是分组变量同时影响了分组比例和结果。**看到分组和总体结论相反时，先找混杂变量，而不是怀疑数据错了。**

**一句话记住**：
> 预测模型回答「谁会买」，因果模型回答「谁会**因为我做了这件事**而买」。
> **按前者发券，钱大部分会花在本来就会买的人身上。**

## 2. 潜在结果框架（Rubin Causal Model）

### 2.1 基本记号

对个体 $i$，定义两个**潜在结果**：
- $Y_i(1)$：接受干预（treatment，如发券）后的结果
- $Y_i(0)$：不接受干预后的结果

个体因果效应 $\tau_i = Y_i(1) - Y_i(0)$。

**因果推断的根本问题**：同一个人不可能既发券又不发券，$Y_i(1)$ 和 $Y_i(0)$ **永远只能观测到一个**，另一个是反事实。
所以**个体效应不可识别**，我们只能求平均：

| 量 | 定义 | 含义 |
|---|---|---|
| **ATE** | $\mathbb{E}[Y(1)-Y(0)]$ | 全体的平均处理效应 |
| **ATT** | $\mathbb{E}[Y(1)-Y(0)\mid T=1]$ | 只在被干预人群上的效应 |
| **CATE** | $\tau(x)=\mathbb{E}[Y(1)-Y(0)\mid X=x]$ | **条件平均处理效应，就是 Uplift 建模的目标** |

**CATE 是这一章的核心** —— 我们要的不是"发券整体有没有用"（那是 AB 实验回答的），
而是"**对哪些人**有用"，好把预算花在刀刃上。

### 2.2 三大假设（要能背，追问必考）

1. **SUTVA（个体处理稳定性）**：个体之间不互相影响，且干预只有一个版本。
   **最容易被违反的一条** —— 社交场景里给 A 发券，A 会告诉朋友 B；双边市场里给部分买家补贴会挤占卖家供给。
   这时实验组和对照组互相污染，估计出来的效应是错的（解决办法是按社群/城市/时间分流，而不是按用户分流）。
2. **可忽略性 / 无混杂**：$(Y(1),Y(0)) \perp T \mid X$ —— 控制住 $X$ 之后，是否被干预与潜在结果无关。
   翻译成人话：**所有同时影响"是否干预"和"结果"的变量都被你观测到并放进 $X$ 了。** 这是最强也最难验证的假设。
3. **正值性 / 重叠**：$0 < P(T=1\mid X=x) < 1$ —— 每种人都有可能被干预也有可能不被干预。
   如果某类人 100% 会被发券，你就永远没有他们的对照，无法估计效应。

**随机实验（AB）为什么是金标准？** 因为随机分配让 $T$ 与所有变量（包括观测不到的）独立，
**假设 2 自动成立，假设 3 由分流比例保证**。剩下要小心的主要是 SUTVA。

### 2.3 什么时候做不了 AB 实验

面试常问"不能做实验怎么办"，先要能说清什么时候不能做：

- **伦理/合规**：不能为了实验故意给一部分用户劣质体验。
- **成本或规模**：品牌广告、线下投放、大版本改版，切不出干净的流量。
- **长期效应**：想知道一年后的留存影响，等不起。
- **溢出严重**：社交、双边市场，SUTVA 直接不成立。
- **历史数据已经产生**：只有观测数据，事情已经发生了。

这时才需要 §7 的观测数据方法。**顺序不能反 —— 能做实验就做实验，观测方法的假设强得多、可信度低得多。**

## 3. Uplift 建模：从响应到增量

### 3.1 四象限（必答）

按「干预时会不会转化」× 「不干预时会不会转化」把用户分成四类：

| 类型 | 不发券 | 发券 | uplift | 该不该发 |
|---|---|---|---|---|
| **说服型**（Persuadables） | 不买 | 买 | **正，最大** | **只应该发给这群人** |
| **确定型**（Sure Things） | 买 | 买 | 0 | 不该发，纯损失利润 |
| **无动于衷**（Lost Causes） | 不买 | 不买 | 0 | 不该发，浪费预算 |
| **勿扰型**（Sleeping Dogs） | 买 | 不买 | **负** | **绝对不能发**，发了反而掉转化 |

**「勿扰型」是这套框架最反直觉也最值钱的部分**：过度打扰会让用户反感甚至卸载 App，
Push 场景里这类人真实存在。响应模型永远发现不了他们，因为响应模型只看"会不会转化"。

**Q：为什么响应模型（预测购买概率）不能直接用来发券？（高频）**
响应模型排序靠前的是"购买概率高的人"，这里面**绝大多数是确定型** —— 他们本来就要买。
把券发给他们，转化率数字很好看（因为他们本来就会转化），但**增量为零，还白送了折扣**。
要找的是「发了才买」的说服型，那是 $\tau(x)=P(Y=1|T=1,X)-P(Y=1|T=0,X)$ 最大的人，
**和 $P(Y=1|X)$ 最大的人是两拨人**。

### 3.2 数据从哪来

Uplift 模型的训练数据**必须来自随机实验**：随机分实验组（发券）和对照组（不发），
两组的行为日志合起来就是训练集，$T$ 是组标签，$Y$ 是转化。

**没有随机对照组就训不出可信的 uplift 模型** —— 这是最常见的落地障碍，
所以成熟的团队会**长期保留一小块随机流量（holdout）**专门用来做因果分析和模型迭代。

## 4. Uplift 建模方法

### 4.1 Meta-Learner 三兄弟

**S-Learner（Single）**：把 $T$ 当成一个普通特征，训一个模型 $\mu(x,t)$，预测时
$$\hat\tau(x)=\mu(x,1)-\mu(x,0)$$
- 优点：简单，只训一个模型，数据全用上。
- **缺点**：树模型可能**根本不选 $T$ 做分裂**（uplift 信号通常远弱于主效应），导致 $\hat\tau$ 被压向 0。**倾向于低估效应。**

**T-Learner（Two）**：实验组和对照组**各训一个模型** $\mu_1(x)$、$\mu_0(x)$，
$$\hat\tau(x)=\mu_1(x)-\mu_0(x)$$
- 优点：不会忽略 $T$，两组数据形态差异大时更灵活。
- **缺点**：两个模型各自的误差会**直接叠加**到差值上；某一组样本很少时（对照组通常小）方差很大。

**X-Learner**：针对"两组样本量严重不均"设计，三步：
1. 先和 T-Learner 一样训出 $\mu_0,\mu_1$。
2. **交叉插补**每个个体的效应：
   对实验组个体 $\tilde D_i^1 = Y_i - \mu_0(X_i)$；对对照组个体 $\tilde D_i^0 = \mu_1(X_i) - Y_i$。
3. 用 $\tilde D^1$ 训 $\tau_1(x)$、用 $\tilde D^0$ 训 $\tau_0(x)$，再用倾向得分 $g(x)$ 加权组合：
   $$\hat\tau(x)=g(x)\,\tau_0(x)+(1-g(x))\,\tau_1(x)$$
- **直觉**：样本多的那一组能训出更可靠的模型，就让它去为样本少的那一组"补"反事实。〔Künzel et al., PNAS 2019〕

### 4.2 直接建模 uplift

**类别变换法（Class Transformation）**：当 $P(T=1)=0.5$ 时，构造新标签
$$Z_i = \begin{cases}1 & (T_i=1,Y_i=1)\ \text{或}\ (T_i=0,Y_i=0)\\ 0 & \text{其他}\end{cases}$$
可以证明 $\tau(x) = 2P(Z=1\mid X=x)-1$。
**于是一个普通的二分类模型就能直接输出 uplift** —— 优雅，但要求处理组比例是 1:1（不然要加权修正）。

**因果树 / 因果森林**〔Athey & Imbens, PNAS 2016；Wager & Athey, JASA 2018〕：
把决策树的分裂准则从「最小化预测误差」换成「**最大化子节点之间处理效应的差异**」，
直接朝着"找出效应不同的人群"去切分。

关键设计是 **honest splitting（诚实分裂）**：把样本一分为二，
**一半只用来决定树结构，另一半只用来估计每个叶子的效应**。
这样叶子内的效应估计不受"选择这个切分"的偏差影响，能给出有效的置信区间。
**这个设计值得记 —— 它是"用同一份数据既选模型又估参数会过拟合"的一个干净解法。**

### 4.3 怎么选

| 场景 | 建议 |
|---|---|
| 两组样本量接近、效应较强 | T-Learner 或类别变换，简单直接 |
| 对照组很小（常见，因为对照组是"损失"的流量） | **X-Learner** |
| 想要置信区间、要做人群解释 | **因果森林** |
| 特征多、想复用现有排序模型 | S-Learner 起步，但要检查 $T$ 有没有真的被用上 |

## 5. 怎么评估（这里最容易答砸）

**Q：能用 AUC 评估 uplift 模型吗？** **不能。**
AUC 需要每条样本的真实标签，而**个体的真实 uplift $\tau_i$ 永远观测不到**（反事实缺失）。
所以 uplift 的评估只能在**分组层面**做。

**Qini 曲线 / 增益曲线**的做法：
1. 用模型给测试集（同样来自随机实验）打分，按预测 uplift **降序排列**。
2. 取前 $k$ 比例的人，分别统计其中实验组的转化数 $Y_T(k)$、对照组的转化数 $Y_C(k)$，以及各自人数 $N_T(k),N_C(k)$。
3. 累计增量
   $$\text{Qini}(k)=Y_T(k)-Y_C(k)\cdot\frac{N_T(k)}{N_C(k)}$$
   （后一项是把对照组按人数比例缩放到与实验组可比）
4. 横轴取比例、纵轴取累计增量画曲线，与「随机排序」的对角线之间的面积就是 **Qini 系数**；AUUC 是同族指标。

**怎么看这条曲线**：
- 好模型的曲线**先陡后平** —— 说明它把说服型排在了前面。
- 曲线在末端**往下掉**是好事，说明它识别出了"勿扰型"（发了反而是负收益）。
- 曲线贴着对角线 = 模型没有区分能力，等于随机发。

**更朴素但很好用的做法**：**分位数增益表** —— 按预测 uplift 分十档，逐档算实验组和对照组的转化率差。
好模型应该呈现**单调递减**。这个表业务方一看就懂，比 Qini 系数更容易推动落地。

## 6. 观测数据去偏（做不了实验时）

核心思路都是一样的：**通过调整让实验组和对照组"可比"**，逼近随机化的效果。

| 方法 | 核心思想 | 关键假设 / 风险 |
|---|---|---|
| **倾向得分匹配 PSM** | 先建模 $e(x)=P(T=1\mid X)$，给每个处理个体匹配一个得分接近的对照个体 | 依赖无混杂假设；匹配后必须**检查协变量平衡性** |
| **IPW（逆倾向加权）** | 按 $1/e(x)$ 加权，构造伪总体：$\hat{\mathbb{E}}[Y(1)]=\frac1n\sum\frac{T_iY_i}{e(X_i)}$ | $e(x)$ 接近 0 或 1 时**权重爆炸、方差极大** → 需要截断（clipping） |
| **双重稳健 AIPW** | 同时用倾向得分模型和结果模型 | **两个模型只要有一个是对的，估计就无偏** —— 所以叫"双重稳健"，实践首选 |
| **双重机器学习 DML** | 用 ML 估计两个 nuisance 函数，再做正交化 + **cross-fitting**（交叉拟合避免过拟合偏差）〔Chernozhukov et al., 2018〕 | 让 ML 模型能安全地用于因果估计，是现在的主流框架 |
| **DID（双重差分）** | 用「处理组前后之差 − 对照组前后之差」抵消掉不随时间变化的混杂 | **平行趋势假设**：没有干预的话两组本应同步变化。要用干预前的多期数据检验 |
| **断点回归 RDD** | 利用规则阈值（如积分 ≥ 1000 才发券），比较阈值两侧的人 | 只能估计**阈值附近**的局部效应，外推不了 |
| **工具变量 IV** | 找一个只通过 $T$ 影响 $Y$ 的变量 | 好工具变量极难找，且假设无法完全检验 |

**面试要点**：这些方法**都只能处理观测到的混杂**。
如果存在一个你没记录的变量同时影响干预和结果（**未观测混杂**），上面所有方法都会有偏。
**能主动说出这条局限，比背出七个方法名更能体现你真的理解。**

## 7. 在推荐 / 广告 / 增长里的实际应用

**优惠券与补贴**：预算有限时按预测 uplift 降序发，而不是按购买概率。
典型收益是"同样的预算，增量 GMV 提升 20%+，或者同样的增量只花一半预算"（**量级是示意，具体看业务**）。

**Push / 短信触达**：核心价值往往在**识别勿扰型**。少打扰这批人带来的留存收益，
经常大于多打扰带来的点击收益。**这个 trade-off 说得出来会很加分。**

**广告增量（Incrementality）**：广告主关心的是"这次投放**多**带来多少转化"，
而不是归因平台报的转化数（那里面包含大量本来就会转化的人）。
做法是留出**对照组不投广告**（或投公益广告 PSA），对比转化差异 —— 这就是随机实验。
**「归因转化 ≠ 增量转化」是广告方向的高频考点。**

**位置偏置其实也是因果问题**：$P(\text{点击})=P(\text{看到}\mid\text{位置})\times P(\text{点击}\mid\text{看到})$，
位置是干预，[05 §6.4](05-recsys-ads.md) 的 PAL 和 IPW 用的正是本章的思路。
**能把这两块联系起来，说明你形成了体系而不是记了两个孤立知识点。**

**长期效应与代理指标**：短期 CTR 涨不代表长期留存涨（标题党就是典型）。
判断长期效应要靠**长周期反转实验**（holdback）或代理指标的因果验证，见 [11 §2](11-system-design.md)。
