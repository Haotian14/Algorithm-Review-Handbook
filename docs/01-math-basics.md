## 1. 线性代数

### 1.1 矩阵分解速查

| 分解 | 形式 | 适用 | 用途 |
|---|---|---|---|
| 特征分解 | $A = Q\Lambda Q^{-1}$ | 方阵 | PCA、谱聚类、马尔可夫稳态 |
| 对称特征分解 | $A = Q\Lambda Q^{T}$，$Q$ 正交 | 实对称阵 | 协方差矩阵 |
| SVD | $A = U\Sigma V^{T}$ | 任意矩阵 | 降维、推荐系统 MF、低秩近似（LoRA 的理论来源） |
| Cholesky | $A = LL^{T}$ | 对称正定 | 高斯采样、求解线性方程组 |

**必答：SVD 和特征分解的关系？**
$A^{T}A = V\Sigma^{2}V^{T}$，$AA^{T} = U\Sigma^{2}U^{T}$。即 $V$ 是 $A^{T}A$ 的特征向量，$U$ 是 $AA^{T}$ 的特征向量，奇异值是特征值的平方根。SVD 对任意矩阵都存在，特征分解只对方阵。

### 1.2 PCA 完整推导（必背）

**目标**：找一组正交基，把数据投影上去后方差最大（等价于重构误差最小）。

1. 数据中心化：$X \leftarrow X - \bar{X}$（**必须做**，否则第一主成分会指向均值方向）。
2. 协方差矩阵 $C = \frac{1}{n}X^{T}X$，$C$ 是实对称半正定矩阵。
3. 求投影方向 $w$（$\|w\|=1$）使投影方差 $w^{T}Cw$ 最大。
4. 拉格朗日：$L = w^{T}Cw - \lambda(w^{T}w-1)$，求导得 $Cw = \lambda w$。
5. 所以 $w$ 就是 $C$ 的特征向量，方差就是对应特征值 $\lambda$。取前 $k$ 大特征值对应的特征向量。

**追问 1：为什么协方差矩阵一定半正定？**
对任意 $v$：$v^{T}Cv = \frac{1}{n}v^{T}X^{T}Xv = \frac{1}{n}\|Xv\|^{2} \ge 0$。

**追问 2：PCA 需要标准化吗？**
如果各维量纲不同（比如身高 cm 和体重 kg），必须标准化，否则数值大的维度主导方差。量纲一致时只需中心化。

**追问 3：PCA 和 SVD 的实际实现？**
实际中直接对中心化后的 $X$ 做 SVD：$X = U\Sigma V^{T}$，主成分方向就是 $V$ 的列，避免显式构造 $d\times d$ 的协方差矩阵（$d$ 很大时开销大且数值不稳）。

**追问 4：PCA 的缺陷？**
线性方法（非线性结构用 t-SNE/UMAP/AutoEncoder）；无监督，最大方差方向不一定是最有判别力的方向（对比 LDA）；对异常值敏感。

### 1.3 范数与几何直觉

- $L_0$：非零元素个数，NP-hard，不可导。
- $L_1 = \sum|w_i|$：等值面是菱形，顶点在坐标轴上 → 与损失等高线相切时容易切在顶点 → **稀疏解**。
- $L_2 = \sqrt{\sum w_i^{2}}$：等值面是圆，切点一般不在轴上 → 权重变小但不为零。
- 谱范数：最大奇异值，用于 Lipschitz 约束（WGAN-GP、谱归一化）。

## 2. 概率与统计

### 2.1 极大似然估计与损失函数的对应（高频）

MLE：$\hat\theta = \arg\max_\theta \prod_i p(x_i|\theta)$，取对数变成 $\arg\max \sum_i \log p(x_i|\theta)$。

| 假设的噪声/似然 | 等价的损失函数 |
|---|---|
| 高斯噪声 $y = f(x)+\mathcal{N}(0,\sigma^2)$ | MSE（均方误差） |
| 拉普拉斯噪声 | MAE（L1 损失） |
| 伯努利分布 | 二分类交叉熵 = LogLoss |
| 多项分布 | 多分类交叉熵 |

**"交叉熵和 MLE 什么关系"标准答案**：
最小化交叉熵 $-\sum_i \sum_c y_{ic}\log \hat{y}_{ic}$ ⟺ 最大化对数似然 ⟺ 最小化经验分布与模型分布的 KL 散度（因为 $\text{CE}(p,q) = H(p) + \text{KL}(p\|q)$，$H(p)$ 是常数）。

**加上先验就是 MAP**：$L_2$ 正则 ⟺ 高斯先验；$L_1$ 正则 ⟺ 拉普拉斯先验。这条经常被追问。

### 2.2 信息论三件套

| 概念 | 公式 | 直觉 |
|---|---|---|
| 熵 | $H(p) = -\sum p\log p$ | 分布的不确定性/最优编码长度 |
| 交叉熵 | $H(p,q) = -\sum p\log q$ | 用 $q$ 的编码去编码 $p$ 的平均长度 |
| KL 散度 | $\text{KL}(p\|q) = \sum p\log\frac{p}{q}$ | 多付出的编码代价，$\ge 0$，**不对称** |
| JS 散度 | $\frac12\text{KL}(p\|m)+\frac12\text{KL}(q\|m)$ | 对称化，原始 GAN 的目标 |

**追问：为什么 KL 不对称会有问题？**
$\text{KL}(p\|q)$（forward，"mean-seeking"）在 $p>0$ 而 $q\to 0$ 处惩罚巨大 → $q$ 会覆盖 $p$ 的所有模式，倾向于摊平。$\text{KL}(q\|p)$（reverse，"mode-seeking"）会让 $q$ 收缩到 $p$ 的某个峰上 → VAE 用 reverse KL 会有后验坍缩；RLHF 里用 KL 惩罚防止策略跑偏也是这个形式。

### 2.3 偏差-方差分解（必背）

$$\mathbb{E}[(y-\hat f)^2] = \underbrace{(\mathbb{E}[\hat f]-f)^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}[(\hat f - \mathbb{E}[\hat f])^2]}_{\text{Variance}} + \underbrace{\sigma^2}_{\text{噪声}}$$

- 高偏差 = 欠拟合：模型太简单 → 加特征、加深模型、减正则。
- 高方差 = 过拟合：模型太复杂 → 加数据、加正则、Dropout、早停、集成。
- **Bagging 主要降方差**（并行独立模型取平均），**Boosting 主要降偏差**（串行拟合残差）。这是随机森林 vs GBDT 的核心区别。

### 2.4 常见分布速查

| 分布 | 场景 | 期望/方差 |
|---|---|---|
| 伯努利 $B(p)$ | 单次点击/不点击 | $p$ / $p(1-p)$ |
| 二项 $B(n,p)$ | $n$ 次曝光的点击数 | $np$ / $np(1-p)$ |
| 泊松 $\text{Pois}(\lambda)$ | 单位时间事件数（QPS、请求量） | $\lambda$ / $\lambda$ |
| 指数 $\text{Exp}(\lambda)$ | 事件间隔时间，无记忆性 | $1/\lambda$ / $1/\lambda^2$ |
| 高斯 | 中心极限定理的产物 | $\mu$ / $\sigma^2$ |
| Beta | 伯努利的共轭先验（Thompson 采样） | $\frac{\alpha}{\alpha+\beta}$ |

**Beta 分布为什么在推荐里重要**：Thompson Sampling 做探索时，用 Beta$(\alpha+\text{点击数}, \beta+\text{未点击数})$ 维护 CTR 的后验，采样出值排序 → 天然平衡 exploration/exploitation。

### 2.5 假设检验与 A/B 测试

- **p-value**：原假设成立时，观测到当前或更极端结果的概率。**不是**"原假设为真的概率"（这是最常见的错误理解，面试官爱挖）。
- **一类错误 $\alpha$**：弃真（把没效果的当成有效果）；**二类错误 $\beta$**：取伪。功效 = $1-\beta$。
- **样本量估算**：$n \approx \frac{2(z_{\alpha/2}+z_\beta)^2\sigma^2}{\delta^2}$，$\delta$ 是想检测的最小效应。要检测更小的提升，样本量按平方反比增长 —— 这就是为什么 0.1% 的 CTR 提升需要跑很久。
- **多重检验**：同时看 20 个指标，即使全无效也大概率有 1 个"显著"。用 Bonferroni 或 FDR 校正。

## 3. 优化

### 3.1 凸性

- 凸函数：$f(\lambda x+(1-\lambda)y) \le \lambda f(x)+(1-\lambda)f(y)$；二阶条件：Hessian 半正定。
- 凸问题的局部最优 = 全局最优。LR、SVM（原问题）、Lasso 都是凸的；神经网络不是。
- **追问：神经网络非凸为什么还能训好？**
  ① 高维空间中"坏的局部极小"很少，大部分驻点是**鞍点**，而 SGD 的噪声能逃离鞍点；② 过参数化下损失面存在大量近似等价的平坦极小值；③ 平坦极小值泛化更好（Sharp vs Flat minima）。

### 3.2 梯度下降家族

| 方法 | 更新 | 特点 |
|---|---|---|
| BGD | 全量梯度 | 稳定但慢，内存爆 |
| SGD | 单样本 | 噪声大，能逃鞍点 |
| Mini-batch SGD | batch | 实际标配，兼顾稳定与效率 |

**batch size 的影响**：大 batch → 梯度估计更准、并行效率高，但噪声小容易收敛到 sharp minima，泛化变差；需要配合线性缩放学习率（$lr \propto \text{batch}$）+ warmup（见 [03 深度学习](03-deep-learning.md)）。

### 3.3 拉格朗日对偶（SVM 的前置）

原问题 $\min_x f(x)\ \text{s.t.}\ g_i(x)\le 0$，构造 $L(x,\alpha)=f(x)+\sum\alpha_i g_i(x)$，对偶问题 $\max_{\alpha\ge0}\min_x L$。

**KKT 条件**（强对偶时的充要条件）：
1. 平稳性 $\nabla_x L = 0$
2. 原始可行 $g_i(x)\le 0$
3. 对偶可行 $\alpha_i \ge 0$
4. **互补松弛 $\alpha_i g_i(x)=0$** ← SVM 中"只有支持向量的 $\alpha>0$"就是这条

## 4. 概率面试题（高频原题）

**Q1. 三门问题**：换。初始选中概率 1/3，主持人开门后不换仍是 1/3，换则是 2/3。核心是主持人**知道**门后是什么，他的行为携带信息。

**Q2. 用不均匀硬币（正面概率 p）生成等概率 0/1**
连抛两次：正反 → 输出 0，反正 → 输出 1，两次相同则重抛。因为 $P(\text{正反}) = P(\text{反正}) = p(1-p)$。

**Q3. 用 rand5 生成 rand7**
`(rand5()-1)*5 + rand5()` 得到 1~25 均匀，取 1~21 部分，`(x-1)%7+1`，>21 重来。期望调用次数 $\frac{25}{21}\times 2 \approx 2.38$。

**Q4. 蓄水池抽样（数据流中等概率取 k 个）**
前 k 个直接放入；第 $i$ 个（$i>k$）以概率 $k/i$ 替换池中随机一个。
归纳法证明每个元素最终留下的概率都是 $k/n$。代码见 [09 手撕代码](09-coding-ml-scratch.md)。

**Q5. 疾病检测（贝叶斯）**
发病率 0.1%，检测准确率 99%（灵敏度=特异度=99%），检测阳性真患病概率？
$$P(D|+) = \frac{0.99\times0.001}{0.99\times0.001+0.01\times0.999} \approx 9\%$$
**结论**：低发病率下即使高准确率，阳性预测值也很低 —— 这就是不平衡数据下 accuracy 无意义、要看 precision 的直觉来源。

**Q6. 抛硬币直到连续两个正面，期望次数？**
设 $E_0$（当前无连续正）、$E_1$（当前已有一个正）。
$E_0 = 1 + \frac12 E_1 + \frac12 E_0$，$E_1 = 1 + \frac12\cdot 0 + \frac12 E_0$。
解得 $E_0 = 6$。（连续 $n$ 个正面的期望是 $2^{n+1}-2$。）

**Q7. 一根长度为 1 的棍子随机折两刀，能组成三角形的概率？**
$1/4$。设断点 $x,y$，三角形条件要求每段 < 1/2，在单位正方形中画出可行域面积为 1/4。
